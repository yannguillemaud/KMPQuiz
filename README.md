# 🧠🚀 KMP Quiz

**KMP Quiz** is a personal side-project built with **Kotlin Multiplatform**.  
The goal: **train memory** by answering multiple-choice quizzes on various topics, with **regular
reminders** ⏰

---

## 🎯 Motivation

This project is a personal side-project built with Kotlin Multiplatform to explore the potential of
the Compose Multiplateform framework.
POC started with:

- fetch **Q&As** from sources (**API, Github repository..**)
- train memory by answering quizzes
- set reminders to train regularly

Over time, new features were introduced. More may be on the way.

---

## ✨ Features

- 🔗 **Multi-APIs fetching** - fetch your Q&A from multiple apis
- 📚 **Multi-topic quizzes** – train your memory across different subjects
- 🔔 **Notifications** – stay consistent with regular reminders
- 🌐 **Cross-platform** – powered by Kotlin Multiplatform Mobile (KMM), **but only supports Android
  platform *yet***
- 📊 **Progress tracking** – scores, history, spaced repetition

---

## 🔜 Coming features

- 🎮️ **Multiplayer Mode** - sync or async quizzes with friends

---

## 🛠️ Tech Stack

- **Kotlin Multiplatform (KMM)** – shared business logic for Android & iOS
- **Jetpack Compose** - UI with Material3 design and layouts
- **SQLDelight** – persistence
- **Ktor** – networking
- **Grant** – permissions
- **Koin** – dependency injection
